# Jarin Akther Salvi, Portfolio

A static personal site: open `index.html` in a browser, or run `node server.js` and visit http://localhost:3000.

- Put your photo at `assets/profile.jpg`.
- Research links open through `links.json`. Replace the URLs there with your exact IEEE Xplore profile and paper pages.
- Three.js and Google Fonts load from a CDN, so the first visit needs internet.
